# Развёртывание на VPS (Ubuntu 22.04/24.04)

Пошаговая инструкция для разворачивания «Легендариума» на арендованном
виртуальном сервере. Рассчитана на минимальную конфигурацию: 2 vCPU, 2-4 ГБ RAM,
30-40 ГБ SSD.

Везде ниже `your-domain.ru` — ваш домен (например, `legendarium-folk.ru`), а в примерах
команд для краткости используется именно `legendarium-folk.ru`. Если домена пока нет —
можно работать по IP сервера, пропустив пункты про DNS и SSL.

## 0. Где арендовать VPS

Для проекта достаточно самого простого тарифа: 2 vCPU, 2-4 ГБ RAM, 30-40 ГБ SSD,
Ubuntu 22.04/24.04. Ориентировочные цены на момент защиты ВКР:

| Провайдер | Примерная цена | Комментарий |
|---|---|---|
| Timeweb Cloud | от ~250-350 ₽/мес | Российский хостинг, оплата картой РФ, серверы в РФ — быстро для российских пользователей |
| REG.RU (VPS) | от ~300-400 ₽/мес | Можно сразу же привязать домен, если он куплен там же |
| Beget VDS | от ~300 ₽/мес | Простая панель управления, подходит новичкам |
| Selectel | от ~300 ₽/мес | Гибкая тарификация, оплата по часам |
| Hetzner Cloud | от ~€4 (≈400 ₽)/мес | Очень дёшево и надёжно, но сервер в ЕС — для пользователей из РФ задержка чуть выше; оплата картой РФ может не пройти |

Для рабочего демо на защите хватит самого дешёвого тарифа любого из российских
провайдеров (Timeweb/REG.RU/Beget) — это 250-400 ₽/мес.

### Можно ли бесплатно?

- **Oracle Cloud Free Tier** — единственный вариант с по-настоящему бессрочно
  бесплатным VPS (ARM-сервер, до 4 vCPU / 24 ГБ RAM хватит с большим запасом).
  Минус: регистрация требует иностранную карту и подтверждение, доступ из РФ
  затруднён, аккаунты часто блокируют без видимой причины — рискованно закладывать
  это в план перед защитой.
- **Render / Railway / Fly.io** — есть бесплатные тарифы для Node.js + Postgres,
  но: сервер «засыпает» при простое (первый запрос после паузы грузится 10-30 сек),
  бесплатная база данных обычно имеет лимит по объёму и времени жизни (например,
  Render удаляет бесплатную БД через 90 дней), а серверы расположены за пределами
  РФ — для жюри открыть один раз вполне нормально, но для постоянной работы не
  годится.
- **Yandex Cloud / VK Cloud** — дают грантовые баллы новым пользователям
  (обычно на 1-2 месяца), которых достаточно, чтобы бесплатно прогнать проект
  весь период подготовки к защите.

**Рекомендация:** для демонстрации комиссии надёжнее взять самый дешёвый платный
VPS у российского провайдера (Timeweb/REG.RU/Beget, ~250-350 ₽/мес) — это
копейки, но даёт стабильный аккаунт без рисков блокировки и без "засыпания"
сервера прямо во время презентации.

## 1. Первичная настройка сервера

Подключитесь по SSH (данные выдаёт хостинг-провайдер после создания сервера):

```bash
ssh root@<IP сервера>
```

Обновите систему и создайте отдельного пользователя (работать под root постоянно небезопасно):

```bash
apt update && apt upgrade -y
adduser deploy
usermod -aG sudo deploy
su - deploy
```

## 2. Установка зависимостей

### Node.js (через nvm — проще управлять версиями)

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install 20
node -v   # должно быть v20.x
```

### PostgreSQL

```bash
sudo apt install -y postgresql postgresql-contrib
sudo -u postgres psql -c "CREATE USER legendarium WITH PASSWORD 'СГЕНЕРИРУЙТЕ_СЛОЖНЫЙ_ПАРОЛЬ';"
sudo -u postgres psql -c "CREATE DATABASE legendariumdb OWNER legendarium;"
```

### nginx и certbot (для HTTPS)

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

### PM2 (менеджер процессов Node.js)

```bash
npm install -g pm2
```

## 3. Клонирование и настройка проекта

```bash
git clone https://github.com/Albie-source/VKR_Legenderium.git
cd VKR_Legenderium
npm ci
```

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
nano .env
```

Заполните реальными значениями:

```ini
DATABASE_URL="postgresql://legendarium:СГЕНЕРИРУЙТЕ_СЛОЖНЫЙ_ПАРОЛЬ@localhost:5432/legendariumdb"

# Сгенерировать: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
SESSION_SECRET="<сгенерированная случайная строка не короче 32 символов>"

YANDEX_TTS_API_KEY="<ваш ключ, если используете озвучку>"
```

## 4. Миграции базы данных и сборка

```bash
npx prisma migrate deploy
# при необходимости заполнить начальными данными:
# npx prisma db seed

npm run build
```

## 5. Запуск через PM2

В репозитории уже есть `ecosystem.config.js`. Запустите приложение:

```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup   # выполните команду, которую выведет pm2 startup — это включит автозапуск при перезагрузке сервера
```

Проверить, что приложение работает:

```bash
curl http://localhost:3000
pm2 logs legendarium
```

## 6. Настройка DNS (привязка домена к серверу)

Прежде чем выпускать SSL-сертификат, домен должен указывать на IP вашего VPS.

1. Узнайте IP-адрес сервера (показывается в панели провайдера VPS после создания).
2. Зайдите в панель управления домена `legendarium-folk.ru` (там, где он куплен —
   например REG.RU, Timeweb и т.д.) → раздел **DNS** / **Управление зоной**.
3. Добавьте (или измените) записи:

   | Тип | Имя (хост) | Значение | TTL |
   |---|---|---|---|
   | A | `@` (или пусто, означает корень домена) | `IP вашего VPS` | по умолчанию |
   | A | `www` | `IP вашего VPS` | по умолчанию |

4. Подождите, пока DNS обновится (обычно от нескольких минут до часа). Проверить:

```bash
ping legendarium-folk.ru
# в ответе должен быть IP вашего сервера
```

Только после того, как `ping` показывает правильный IP, переходите к выпуску
SSL-сертификата в следующем шаге — иначе certbot не сможет подтвердить домен.

## 7. nginx как reverse proxy + HTTPS

В репозитории есть пример конфигурации `deploy/nginx.conf.example`. Скопируйте
его на сервер, подставьте свой домен:

```bash
sudo cp deploy/nginx.conf.example /etc/nginx/sites-available/legendarium
sudo nano /etc/nginx/sites-available/legendarium   # замените your-domain.ru на legendarium-folk.ru (и www.legendarium-folk.ru)
sudo ln -s /etc/nginx/sites-available/legendarium /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

Выпустите бесплатный SSL-сертификат Let's Encrypt:

```bash
sudo certbot --nginx -d legendarium-folk.ru -d www.legendarium-folk.ru
```

certbot сам пропишет HTTPS в конфиг nginx и настроит автопродление сертификата.

## 8. Открытие портов (firewall)

```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
```

## 9. Обновление приложения после правок в коде

Когда в проект внесены изменения и их нужно выкатить на сервер:

```bash
cd ~/VKR_Legenderium
git pull origin main          # или нужная ветка
npm ci
npx prisma migrate deploy     # если менялась схема БД
npm run build
pm2 restart legendarium
```

## 10. Резервное копирование

Настройте регулярные бэкапы — терять реальные пользовательские данные перед
защитой обидно:

```bash
# дамп базы данных
pg_dump -U legendarium legendariumdb > backup_$(date +%F).sql

# архив загруженных медиафайлов
tar -czf uploads_$(date +%F).tar.gz ~/VKR_Legenderium/public/uploads
```

Можно положить эти команды в cron (`crontab -e`) для автоматического запуска,
например, раз в сутки.
